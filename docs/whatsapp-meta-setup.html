Oman Sale — WhatsApp OTP

دليل إعداد حساب Meta وربط واتساب للتحقق من الهاتف

يشرح هذا الدليل كيفية إنشاء تطبيق Meta، تجهيز WhatsApp Business API، إنشاء قالب رمز التحقق (OTP)، ثم إدخال القيم في ملف .env ليعمل النظام تلقائياً مع التسجيل وإنشاء المتجر.

كيف يعمل النظام عندك؟

  1. المستخدم يطلب رمز تحقق للهاتف (تسجيل حساب أو رقم متجر جديد).
  2. الـ API يولّد رمزاً من 6 أرقام ويضعه في طابور Redis (notifications).
  3. عملية الـ Worker (npm run dev:worker) تستلم المهمة وترسلها إلى Meta Graph API.
  4. Meta يرسل رسالة واتساب باستخدام قالب OTP معتمد.
  5. المستخدم يدخل الرمز في الواجهة، والـ API يتحقق منه.
مهم: بدون تشغيل Worker + Redis لن تُرسل رسائل واتساب حتى لو كانت إعدادات Meta صحيحة.

المرحلة 1 — إنشاء حساب Meta للمطورين

  1. ادخل إلى Meta for Developers وسجّل الدخول بحساب فيسبوك/إنستغرام.
  2. من القائمة: My Apps → Create App. اختر نوع التطبيق Business (أو Other إذا لم يظهر Business).
  3. أدخل اسم التطبيق، مثلاً: Oman Sale WhatsApp، واربطه بـ Business Portfolio (أنشئ واحداً إن لم يكن موجوداً).
  4. بعد الإنشاء، من لوحة التطبيق اضغط Add Product واختر WhatsApp.

المرحلة 2 — ربط WhatsApp Business

  1. من القائمة الجانبية: WhatsApp → API Setup.
  2. أنشئ أو اختر WhatsApp Business Account (WABA).
  3. أضف رقم هاتف للإرسال:
    • للاختبار: يمكن استخدام الرقم التجريبي الذي توفره Meta.
    • للإنتاج: استخدم رقم أعمال حقيقي (+968...) غير مرتبط بواتساب شخصي.
  4. في وضع التطوير، أضف أرقام الاختبار من API Setup → To (حتى 5 أرقام). لن يصل الرمز لأرقام غير مسجلة في الاختبار.
  5. انسخ Phone number ID — ستحتاجه في متغير البيئة WHATSAPP_PHONE_NUMBER_ID.

المرحلة 3 — إنشاء Access Token دائم

لا تستخدم التوكن المؤقت (24 ساعة) في الإنتاج.

  1. افتح Meta Business Settings.
  2. Users → System Users → أنشئ System User (مثلاً: oman-sale-api).
  3. امنحه صلاحية على حساب WhatsApp Business الخاص بك (Assets → WhatsApp accounts).
  4. أنشئ Token مع الصلاحية: whatsapp_business_messaging (ويفضل أيضاً whatsapp_business_management للإدارة).
  5. انسخ التوكن واحفظه في WHATSAPP_ACCESS_TOKEN — لا ترفعه إلى Git.

المرحلة 4 — إنشاء قالب OTP (Authentication)

واتساب لا يسمح بإرسال نص حر لأول مرة. رموز التحقق تُرسل عبر Message Template من فئة Authentication.

  1. من WhatsApp Manager → Message templates اضغط Create template.
  2. اختر الفئة: Authentication.
  3. الاسم (بالإنجليزية فقط، بدون مسافات): oman_sale_otp — يجب أن يطابق WHATSAPP_OTP_TEMPLATE_NAME.
  4. اللغة: Arabic (الكود ar) — يطابق WHATSAPP_OTP_TEMPLATE_LANGUAGE.
  5. نص مقترح للجسم: 
    رمز التحقق الخاص بك في Oman Sale هو {{1}}
لا تشارك هذا الرمز مع أحد.
    المتغير {{1}} هو رمز الـ 6 أرقام.
  6. إذا أضاف Meta زراً (URL / Copy code) في القالب، اترك WHATSAPP_OTP_TEMPLATE_HAS_BUTTON=true. إذا كان القالب نصاً فقط بدون زر، عيّنه false.
  7. أرسل القالب للمراجعة وانتظر الحالة Approved.
يمكنك إنشاء نسخة إنجليزية أيضاً وتعيين WHATSAPP_OTP_TEMPLATE_LANGUAGE_EN=en.

المرحلة 5 — متغيرات البيئة في المشروع

أضف القيم التالية في ملف .env في جذر المشروع:

# تطوير بدون إرسال فعلي (يدخل المستخدم 000000)
# PHONE_SKIP_VERIFY=true

# تفعيل واتساب الحقيقي
WHATSAPP_ENABLED=true
WHATSAPP_API_VERSION=v21.0
WHATSAPP_PHONE_NUMBER_ID=ضع_phone_number_id_هنا
WHATSAPP_ACCESS_TOKEN=ضع_access_token_هنا
WHATSAPP_OTP_TEMPLATE_NAME=oman_sale_otp
WHATSAPP_OTP_TEMPLATE_LANGUAGE=ar
WHATSAPP_OTP_TEMPLATE_HAS_BUTTON=true
PHONE_SKIP_VERIFY=false
المتغير من أين تحصل عليه في Meta
WHATSAPP_PHONE_NUMBER_ID WhatsApp → API Setup → Phone number ID
WHATSAPP_ACCESS_TOKEN Business Settings → System Users → Generate token
WHATSAPP_OTP_TEMPLATE_NAME اسم القالب المعتمد (مثل oman_sale_otp)
WHATSAPP_OTP_TEMPLATE_LANGUAGE كود لغة القالب (ar / en)
WHATSAPP_OTP_TEMPLATE_HAS_BUTTON true إذا القالب يحتوي زر URL/Copy، وإلا false
PHONE_SKIP_VERIFY true محلياً لتخطي الإرسال وقبول 000000

المرحلة 6 — تشغيل الخدمات

  1. تأكد أن Redis يعمل (REDIS_URL في .env).
  2. شغّل الـ API: 
    npm run dev
  3. في طرفية ثانية، شغّل الـ Worker: 
    cd apps/api
npm run dev:worker
  4. جرّب التسجيل أو إنشاء متجر برقم مسجّل في قائمة اختبار Meta.
  5. راقب سجلات Worker — عند النجاح ستظهر: [whatsapp] OTP sent
للإنتاج: استخدم npm run start:worker كخدمة دائمة (systemd / PM2 / Docker).

استكشاف الأخطاء الشائعة

المشكلة الحل
لا تصل الرسالة تأكد من تشغيل Worker، وتسجيل الرقم في قائمة الاختبار، وموافقة القالب.
Template name does not exist اسم القالب أو اللغة في .env لا يطابق القالب المعتمد في Meta.
Invalid parameter على الزر غيّر WHATSAPP_OTP_TEMPLATE_HAS_BUTTON ليطابق تصميم القالب.
WhatsApp is enabled but missing... أكمل WHATSAPP_PHONE_NUMBER_ID و WHATSAPP_ACCESS_TOKEN.
الرمز لا يُقبل تأكد أن PHONE_SKIP_VERIFY=false في الإنتاج.

قائمة تحقق سريعة

  • تطبيق Meta + منتج WhatsApp
  • WhatsApp Business Account + رقم إرسال
  • قالب OTP معتمد (Authentication)
  • Phone Number ID + Access Token في .env
  • WHATSAPP_ENABLED=true و PHONE_SKIP_VERIFY=false
  • Redis يعمل
  • Worker يعمل (dev:worker أو start:worker)
  • أرقام الاختبار مسجلة في Meta (وضع التطوير)
